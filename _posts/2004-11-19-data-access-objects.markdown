For almost a year I try to use Data Access Objects (DAOs) as a primary technology to fetch data from databases. But at this point I come to a conclusion that DAOs become so pissing off. Of course it is true that I don't know a possible solution to the problem. DAOs aren't easy to implement. At least in case when you want to be 100% pattern compliant. Every single DAO should represent a single table in the database. But the question is: How shall I operate on a relational database using a DAO? This is the hardest thing to achieve. Anyone knows a solution?
